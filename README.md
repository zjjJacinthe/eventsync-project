# EventSync project page

**EventSync: Event-Driven Memory Updates for History-Dependent Manipulation**

- Project page: https://zjjJacinthe.github.io/eventsync-project/
- Paper: https://arxiv.org/abs/2610.27917

This repository contains the static project website. GitHub Pages serves the `main` branch from `/ (root)`.

Code and model releases are forthcoming and have independent repository and license settings.

The page uses relative asset paths and requires no build step. Its contents are `index.html`, `style.css`, `app.js`, and `assets/`; `.nojekyll` disables Jekyll processing.
