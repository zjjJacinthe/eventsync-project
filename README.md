# EventSync project page

Static project page for **EventSync: Event-Driven Memory Updates for History-Dependent Manipulation**.

## Preview

Open the existing private preview shared by the project owner. GitHub Pages is not enabled yet.

## Publish on GitHub Pages

When ready to publish:

1. Change this repository visibility to **Public**.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select **main** and **/ (root)**, then click **Save**.
5. Wait for deployment, then check the published URL while signed out.

Expected project URL: https://zjjJacinthe.github.io/eventsync-project/

Code and model repositories have independent visibility settings. The page's Code, Paper, and Models buttons remain Coming soon until their releases are available.

## Files

- `index.html`: page content.
- `style.css`: typography and responsive layouts.
- `app.js`: result charts, table, chapter links, and citation controls.
- `assets/`: figures, videos, posters, and brand icons.
- `.nojekyll`: serve the static files without Jekyll processing.

All page assets use relative paths so they work under the GitHub Pages project URL.
